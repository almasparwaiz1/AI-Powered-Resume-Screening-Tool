# AI-Powered Resume Screening Tool

Finding the right candidate from hundreds of resumes is time-consuming and often inconsistent. This AI-Powered Resume Screening Tool streamlines the hiring process by automatically analyzing resumes, extracting key skills, evaluating experience and education, and ranking candidates based on their relevance to a job description.

Built using modern Natural Language Processing (NLP), semantic embeddings, and machine learning techniques, the system goes beyond simple keyword matching to understand the context of candidate profiles. Recruiters can upload resumes, define job requirements, and instantly receive a ranked list of the most suitable applicants along with detailed skill-gap insights and hiring recommendations.

### Key Features

* Intelligent resume parsing and analysis
* Semantic candidate matching using transformer-based embeddings
* Automated skill extraction and normalization
* Experience and education assessment
* Candidate ranking with match accuracy scores
* Hire/Reject recommendations based on predefined thresholds
* Skills gap analysis highlighting matched and missing skills
* Support for PDF and TXT resume formats
